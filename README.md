# Bhavya AI Research Centre — Website (Next.js)

Founder: **Dinesh Kumar Gupta**
Tagline: Learn AI | Build Skills | Create Opportunities

## Setup

1. Install Node.js LTS from https://nodejs.org
2. Open terminal in this folder:
```bash
npm install
npm run dev
```
3. Open http://localhost:3000

## Update karne layak files

- `lib/site.ts` — phones, social links (YouTube/WhatsApp/Telegram/Instagram/Facebook), courses, agents
- `public/logo.png` — logo (DOCX se extracted)
